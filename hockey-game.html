J.P. Hockey Goalie

An interactive browser mini-game built from scratch in p5.js—featuring custom vector geometry, physics-based saves, and a celebratory penguin goalie.

SPACE Launch the puck toward the crease

SHIFT Drop J.P.’s stick to block the shot

Built With p5.js 2.0, JavaScript
Focus Animation & Interaction

The Build

Every element in the rink—from J.P.’s silhouette to the hockey stick and ice lines—is drawn procedurally in code using custom vertex shapes and trigonometry rather than external image sprites.

Originally prototyped as a sound-reactive experiment using microphone input, the game was adapted for keyboard controls and updated for p5.js 2.0 so visitors can jump right in from any browser without granting mic permissions.
